
## Lossless Compression

- It uses compression algorithm
- It indexes the data, identifies the repeated patterns & group them together
- A special algorithm called "RLE (Run Length Encoding)" will be used for image files.
- The original file can be reconstructed

## Lossy Compression

- A compression Algorithm will be used
- It removes unnecessary data such as extra details on a image, softer sounds that are played at the same time as louder sounds will be removes
- Original File cannot be reconstructed
- Can be applied to image and audio
