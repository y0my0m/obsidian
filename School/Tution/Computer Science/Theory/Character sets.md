What are [[Character sets]]
- A list of characters with its unique binary value

Why unicode was developed?
-  because ascii could only support 256 characters,
-  it only supported western/Latin Languages,
- Therefore unicode was developed with 16 bit format,
- Supporting Approx. 65,000 characters, 
- To represent non-latin language & emojis

Explain how the word "RED" is represented using a character set
- Each and every character has its own unique binary number and that binary number will be sent to the micro-processor to identify the matching character using a character set
- R=82, E=69, D=68

Explain why recording sound with a higher sampling resolution creates a more accurate recording.
- When there's a higher sampling resolution theres a larger dynamic range, making better sound quality by allowing more precise measurements of sound, creating less sound distortions
